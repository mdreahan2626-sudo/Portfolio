# 🌌 Premium 3D Developer Portfolio

A premium, interactive developer portfolio engineered with Next.js (React 19), Tailwind CSS, Framer Motion, and Three.js (React Three Fiber). It features an interactive 3D desktop workspace background, a downloadable resume integration, and a responsive split-screen projects grid.

## 🚀 Key Features

*   **Interactive 3D Workspace**: A reactive 3D developer setup that floats, rotates, and shifts spotlight colors dynamically as you scroll.
*   **Dual-Layout Projects Panel**:
    *   **Desktop**: A side-by-side grid splitting project selection on the left and full highlights on the right.
    *   **Mobile**: Smoothly pivots to a collapsible accordion rendering details inline under the active card.
*   **Custom SVG Tech Icons**: Hand-crafted inline SVG paths representing tools like Next.js, React, Tailwind CSS, PostgreSQL, Supabase, Prisma, Docker, Gemini AI, LangGraph, and Razorpay.
*   **Performance Optimizations**: Fluid exponential scroll interpolation powered by Lenis Smooth Scroll and dynamic component bundles.

## 🛠️ Getting Started

First, install dependencies and spin up the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Production Build

Compile and bundle the project for static hosting (e.g., Vercel, Netlify):

```bash
npm run build
```
